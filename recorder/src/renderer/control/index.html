MOB Recorder

Four modes, in order

Camera records. Edit transcribes it and lets you remove fillers/silences, trim, and clean up the audio. Production generates a title, description, hashtags and chapters from Edit's transcript. Distribution uploads the result (needs a Cloudflare Worker configured under Output → Cloud). Each tab needs the one before it — Edit needs a recording, Production needs Edit's transcript, Distribution needs a Production package.
