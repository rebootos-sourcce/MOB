Lao Tzu, the horizontal (a path with no seat), second ritual picked
Stop one thing and wait instead of rushing in to help
After Lao Tzu · The horizontal
Release
The old pattern, as Shu and Hu
  • Hurry in to help and make it worse
  • Offer the fix nobody asked for
  • Decide that whatever is whole needs one more fix
  • Hands reach before you have decided
Install
Practise this instead
  • Find the one thing making the noise and stop it for the day
  • Ask what finishes by itself if you leave it
  • Say "I will wait" and wait
  • Let the hands rest open
