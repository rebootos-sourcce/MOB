# ATUNED Funnel Storyboard
## From Website Visit to First Experience

### Creative direction

The current funnel is a strong explanation of ATUNED, but it should become an ATUNED experience.

The central rule:

> Don't tell them what ATUNED does. Let ATUNED do something to them.

The funnel should move through:

**Encounter → Curiosity → Interaction → Recognition → Demonstration → Change → Invitation**

The person should leave the funnel thinking:

> “It saw something in me.”

Then:

> “I want to see what else it can see.”

That is the moment where entering ATUNED becomes natural.

---

# 01. ENCOUNTER

## Purpose

Create immediate curiosity without explaining the entire product.

## Above the fold

The first screen should contain the whole story visually.

### Visual

A living human figure or field.

The seven symbolic centers are present.

The figure is not a static illustration. It should feel like an instrument that is already alive.

Subtle movement.

Symbols appear and respond.

The visual should communicate:

**There is something happening inside you.**

### Copy

**Something is running underneath the way you live.**

Small supporting line:

**ATUNED helps you see it.**

### Primary action

**See what's running**

### Remove from the first screen

Do not lead with:

About  
Tiers  
The Test  
Long explanatory paragraphs  
The 112 addresses  
The 21 laws  
The full tool list

The first screen is an invitation, not documentation.

---

# 02. CURIOSITY

## Purpose

Let the person begin interacting before they understand the system.

The system asks one question.

### Question

**What's been following you lately?**

Present symbolic choices rather than ordinary survey buttons.

Possible visual choices:

**Knot**

Something feels stuck.

**Flame**

Something keeps triggering me.

**Closed Door**

Something I keep avoiding.

**Mirror**

I want to understand myself.

**Open Field**

I'm just curious.

**Voice**

I'll tell you.

The symbols should have motion and personality.

The user should feel like they are entering a world rather than filling out a form.

---

# 03. FIRST TOOL: STORY

## Purpose

Demonstrate that ATUNED can work with the person's own material.

Do not explain Story first.

Use it.

### Prompt

**Tell me something that happened.**

The person writes naturally.

Example:

> My boss asked me to present the work and I immediately wanted to avoid it.

### ATUNED response

The sentence remains visible.

The system begins to notice language.

A phrase such as:

**avoid**

becomes visually active.

A symbolic mark appears.

The body responds.

A location illuminates.

A thread begins forming.

### System response

**Avoidance**

Then:

**Where does that land?**

Possible choices:

Chest  
Throat  
Gut  
Head  
Somewhere else

The person chooses.

The visual field changes.

Now the person has experienced the product.

No explanation is required.

---

# 04. RECOGNITION

## Purpose

Give the user authority over what ATUNED sees.

The system should never force an interpretation.

### Prompt

**Is that what you meant?**

Choices:

**That's it**

**Not quite**

**Show me another possibility**

The visual should respond differently to each choice.

If the user rejects the interpretation, the system changes its hypothesis.

This is important.

The product is demonstrating discernment rather than pretending certainty.

---

# 05. SYMBOLIC QUESTIONING

## Purpose

Make the questions feel like ATUNED rather than a personality questionnaire.

Every meaningful question can carry a symbolic layer.

A question can have:

**Question**

**Symbol**

**Motion**

**Color**

**Body relationship**

**Archetypal relationship**

### Example

A Warrior symbol appears.

The question:

**Someone challenges you.**

Two visual paths appear.

One contracts.

One advances.

The user chooses.

The Warrior symbol changes intensity.

The system does not immediately say:

“You are overexpressing Warrior.”

Instead it describes what it sees.

The user remains the authority.

---

# 06. ART QUESTIONS

## Purpose

Introduce nonverbal perception into the funnel.

Art questions should not feel like random personality tests.

They should gather perceptual signal.

### Example

**Which feels more like you right now?**

Present two or more symbolic images.

Possible visual themes:

Tension  
Calm  
Fragmentation  
Expansion  
Isolation  
Connection  
Contraction  
Opening

The person chooses based on immediate recognition.

The system gathers signal without immediately explaining what the choice means.

### Important

Do not tell the user:

“You chose this image because you are X.”

Instead:

Gather.

Compare.

Look for convergence.

Ask when ambiguity matters.

---

# 07. THE FIELD RESPONDS

## Purpose

Show that ATUNED is not simply analyzing text.

The system connects:

**Language → Symbol → Body → Field → Pattern**

### Visual sequence

1. The user's words remain visible.
2. A meaningful word activates.
3. A symbol appears.
4. A body location responds.
5. A thread connects the two.
6. The field changes.
7. A question appears.

The system is visibly building a map.

This is the moment the user should begin thinking:

**“Wait. How did it know that?”**

---

# 08. DEMONSTRATE THE LOOP

## Purpose

Show the actual ATUNED mechanics without explaining them as a feature list.

The user experiences:

### Discover

**What happened?**

The user tells the story.

### Play

**What happens when we work with it?**

A short interactive practice begins.

### Flow

The pattern is named, located, and worked with.

### Embody

The user observes what changed in the body, perception, behavior, or next action.

Then the system hands back to Discover.

### Visual

The four states should behave like one living loop.

**Discover → Play → Flow → Embody → Discover**

It should not look like four numbered website sections.

It is the product's core game loop.

---

# 09. FIRST CHANGE

## Purpose

The user needs to experience a small consequence before being asked to enter the product.

### Transition

The active pattern contracts.

The visual tether tightens.

The system guides the user through a small release or reframe experience.

The visual field changes.

Space opens.

The symbol changes state.

The system pauses.

Silence matters here.

### Question

**What changed?**

Choices:

**I feel different**

**I see it differently**

**Something moved**

**Nothing changed**

**I'm not sure**

Do not assume success.

The person's answer becomes evidence.

---

# 10. BEFORE AND AFTER

## Purpose

Make the change visible without overclaiming.

Show:

**Before**

and

**Now**

Possible dimensions:

Body  
Perception  
Emotion  
Behavior  
Intention

The system should show what was observed.

Not declare a permanent transformation from one interaction.

### Example

**Before**

Avoiding the conversation.

**Now**

I can imagine having it without the same reaction.

The user confirms or corrects the observation.

---

# 11. REVEAL THE LARGER SYSTEM

Only after the person has experienced ATUNED should the funnel explain the larger architecture.

### Copy

**You just experienced one part of the system.**

Then reveal:

**Discover**

See what is happening.

**Play**

Work with it.

**Flow**

Release and observe.

**Embody**

Bring the change into life.

The explanation is now meaningful because the person has already felt the mechanic.

# 13. THE MIRROR MOMENT

## Purpose

Give the person a first glimpse of who they are becoming.

This should not be a generic summary.

It should reflect the evidence gathered during the interaction.

### Example

**Something is becoming clear.**

Then:

**You noticed the avoidance.**

**You stayed with it.**

**You found where it landed.**

**You tested what was underneath it.**

The system begins to describe the person's current path.

Not as a fixed identity.

As an emerging expression.

---

# 14. INVITATION

## Purpose

Convert curiosity into entry.

The user has already experienced the system.

Now the invitation is simple.

### Copy

**This was only the surface.**

**There is more underneath the way you operate.**

Primary action:

**Enter ATUNED**

Secondary:

**See what else is running**

The user should understand why they are entering.

Not because the website told them to buy.

Because they now want to continue the investigation.

---

# 15. ACCOUNT CREATION

## Principle

Do not interrupt the experience unnecessarily.

If the funnel has already collected information, preserve it.

Do not ask the user to repeat themselves.

The transition should feel like:

**Continue your exploration.**

Not:

**Create an account before you can do anything.**

The material already discovered should follow the person into ATUNED.

---

# 16. THE FIRST ATUNED EXPERIENCE

After account creation:

**You already found something.**

The system carries the first story, first signal, first interpretation, and first confirmed or rejected hypothesis forward.

The user enters the full product with context.

The first session continues the story rather than restarting it.

# EXPERIENCE GRAMMAR

The entire funnel should follow this grammar:

## 1. See

**What is happening?**

## 2. Notice

**What keeps happening?**

## 3. Test

**Is this actually true?**

## 4. Change

**What happens if I work with it?**

## 5. Remember

**What changed?**

This is the experience grammar of ATUNED.

---

# VISUAL GRAMMAR

The funnel should use visual state rather than text wherever possible.

### Contraction

Something is tightening.

### Expansion

Something opens.

### Tension

Two possibilities pull against each other.

### Branching

The system presents alternatives.

### Gathering

Multiple signals begin converging.

### Unbinding

A relationship releases.

### Settling

The system becomes quiet.

### Return

The next experience connects back to the previous one.

These should become the visual physics of ATUNED.

# SYMBOLIC LANGUAGE

Symbols should not be decoration.

They should carry system meaning.

A symbol can communicate:

**Archetype**

**Body region**

**Chakra**

**Pattern**

**Question type**

**State**

**Direction**

**Release**

**Integration**

**Recurrence**

The user should gradually learn the symbolic language through interaction.

The system does not need to explain every symbol.

The symbol itself becomes part of the user's vocabulary.

# QUESTION DESIGN

Questions should be:

Short.

Specific.

Perceptual.

One at a time.

Visually embodied.

When ambiguity matters, ask.

Example:

**When you say angry, which one?**

Then present two different visual expressions.

**I want to confront it.**

**I want to hurt someone.**

The user chooses.

The system learns the distinction.

This is more powerful than pretending the word alone tells the whole story.
