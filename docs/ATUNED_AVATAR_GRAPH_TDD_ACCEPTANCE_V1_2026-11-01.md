## Intent: what the system must actually do
A person selects a legitimate Avatar seat or canonical graph node. The system returns **only the person's supported, evidence-qualified connections** from MOB's existing Trace Graph, with corrections and uncertainty preserved. The same graph can later be narrated by Source AI under its own consent rules. The Avatar is a consumer of canonical truth, never an alternative computation of truth, CQ, SQ, DQ or Release state.

**Definition of done for the engineering seam:** compiled canonical-engine tests, read-only/identity/provenance tests, entitlement tests and composed multi-branch tests pass on exact candidate commit; artifacts regenerated by the canonical build; all integration contracts/version changes accepted. **Visual acceptance belongs to the other AI**, and is a separate requirement for shipping the combined product.

## A. Deterministic contract and state machine
**Inputs:** `authorized: boolean`, `profile: {id:string,...}`, `reading: null|{rec:string,unread?:boolean,...}`, `selection`, `engine`, `limit`.
- `selection.kind='seat'`: Root, Sacral, Solar, Heart, Throat, 3rd Eye, Crown (canonical, case-insensitive selection).
- `selection.kind='pattern'`: numeric canonical address ID, **not** a free-form label.
- `selection.kind='structure'`: one of `saboteur,complex,hyper_complex,super_complex` with bounded canonical ID.
- Other layers—including masks, celestial attributes, boundary, ritual, release—**are not currently graph-selectable**. Give `unsupported_selection`; do not silently guess an address.
- Before calling the graph engine, validate explicit authorization, a usable record identity, valid engine, supported selection and `reading.rec === profile.id` when a reading is supplied.
- `AVATAR_GRAPH.project` must be pure/deterministic for identical immutable inputs. No call to `read(CURP)` from UI; use `readSeenOf(CURP)`.
- `status` is a closed vocabulary: `access_denied`, `no_record`, `unavailable`, `unsupported_selection`, `reading_mismatch`, `no_evidence`, `graph_refused`, `partial`, `ready`.
- `readingStatus` is `measured` or `not_measured`. Neither `not_measured` nor `no_evidence` means score 0.
- Outputs are bounded: 1–16 nodes maximum, caller default 10; 6 for existing Avatar UI; `truncated=true` when the configured limit prevents further supported nodes.

**Provenance decision table:**
| Input evidence | May show as personal? | Explicit finding state | Must NOT claim |
|---|---|---|---|
| Registry taxonomy `known` alone | No | `no_evidence` if nothing more | "You have this pattern" |
| Reading-supported derived `inferred` graph edge | Yes with provenance | `not_recorded` / inferred | User confirmation, diagnosis, cause |
| User YES linked to canonical address | Yes | `confirmed` | Clinical or spiritual certainty |
| User NO linked to canonical address | May surface as declined | `rejected` | Affirmed identity |
| YES + NO for same address | Yes with warning | `conflicted` | Force a single true answer |
| Observed release/ritual `targets` an address | Limited contextual evidence | `not_recorded` unless independent YES | Pattern confirmed by release |
| Structural graph `refused` for current reading | No structural chain | `graph_refused` | Unsupported chain |
| Unrelated refused graph input | Only valid subset | `partial` with warning | Full completeness |
| Cross-profile read stamp | No | `reading_mismatch` | Any traversal |
| Invalid engine, graph or intents | No | `unavailable` | A synthetic substitute graph |

## D. Fixture design (no private user data)
- **Blank:** `blankProfile` validated, read not measured, graph has taxonomy but no personalized evidence.
- **Worked canonical:** fixture with real `CHILD` axes and canonical `traceFromRecord` read, using existing R suite.
- **Consent denied:** valid profile plus `authorized:false`, no trace calls.
- **Foreign stamp:** profile A + reading record B; no trace calls, no outputs from B.
- **Story correction:** `ob.yes=[12]`, `ob.no=[12]`, assert `conflicted` with no auto-resolution.
- **Taxonomy-only:** node catalog and `src:'known'` edges; assert no personal readout.
- **Synthetic malformed engine:** throw, non-array intent list, wrong graph shape, malformed neighbors.
- **Cross-branch:** same canonical profile, traced through observatory, summary, Avatar and optional Source; compare graph identity, evidence provenance and score invariance, not word-for-word UI text.
- **Plan sight:** measured vs `unread` vs null `readSeenOf`; verify no hidden chained structure leaks. Entitlement and privacy are source-of-truth constraints, not just UI badges.
