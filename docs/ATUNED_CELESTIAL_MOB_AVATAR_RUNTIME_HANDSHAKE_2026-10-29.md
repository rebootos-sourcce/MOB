## What actually runs in the app
MOB builds the app as an ordered single-file HTML using `atuned_src/MANIFEST` and `atuned_src/BUILD.sh`. In that order:
1. Generated `engine/data/celestial_snapshot.js` provides 36 canonical-source *read fields*, 15 authored comparison groups, and SHA pointers for 15 original JSON files. It is a **build snapshot** rather than the authoritative editorial repository. Four depth passes remain in Reboot canon, not duplicated in the UI bundle.
2. `engine/celestial_portal.js` packages the exact Reboot-OS record resolver, overlap prototype, Source OS reading builder, Human Design partial peer contract, Avatar cascade and UI renderer as a browser-global `AT_CELESTIAL`. Original module blob SHAs are listed in the generated file header; no network calls or personal-data writes.
3. `ui/celestialui.js` mounts in `ui/avatarui.js#renderAvatar` through a `[data-avcelestial]` host, on all three Avatar subtabs. The panel starts **closed**; it only resolves Celestial context on a user click.
4. Input IDs come from existing `ui/summary.js#sumBirth` which uses existing MOB birth/ephemeris, Eastern animal and `numerologyOf` life path. Missing, ambiguous or unavailable IDs remain unresolved. `sp.hd` carries only existing partial Human Design solar gate/line and profile; never fabricate Type/Authority.
5. `engine/trace.js#traceFromRecord` supplies a **derived read-only** actual existing Trace Graph, never an invented Celestial graph edge. It can include observed/user-confirmed story or pattern edges; the overlay navigates these paths only.
6. `CURP.avatar.pairs` supplies the person's own `be/notbe` goals. The selector changes which coherent or limiting possibility is displayed but **does not alter progress, versions, pair text or CQ**. The six mask labels are Reboot-OS Influence Layer view labels, not claims about an active psychological mask.
7. The controls live inside the new Avatar panel: mask, avatar pair, and focused trace node. Changing a mask adjusts the coherent/shadow questions; nothing is stored in CURP. The panel is disposed on repaint/profile change.
8. The whole system is offline, content-provenanced and read-only. No API requests or inferred psychology writes are part of this seam.
