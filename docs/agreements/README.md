## Status terms

- **DOCUMENTED:** present in an identified source document.
- **OWNER-RECORDED:** a business/product choice is recorded in DECISIONS.md or another authoritative owner record.
- **IMPLEMENTATION UNVERIFIED:** source wording or a proposed contract exists, but the current deployed path has not been proven.
- **DECISION REQUIRED:** an owner must select a business/product policy.
- **COUNSEL REQUIRED:** legal applicability or wording needs qualified legal review.
- **BLOCKED:** the artifact cannot be approved or published until the named dependency is resolved.
- **APPROVED:** use only with explicit recorded owner/counsel approval evidence. No artifact in this pack is marked approved.

Generated legal HTML is not a source of truth. The charter defines evidence precedence for this pack; it does not replace owner decisions, exact code/runtime evidence or counsel approval. Change root Markdown sources, run the documented renderer, and validate generated output only after legal text is approved. Do not hand-edit generated HTML, remove draft warnings or noindex state, enable profile sync, enable production billing, deploy, migrate production data, or issue production gifts as part of this documentation work.
