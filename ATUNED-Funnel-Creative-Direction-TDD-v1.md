# 0. PURPOSE

This document defines the creative direction for the ATUNED public funnel, onboarding experience, and first tutorial experience.

It expands the existing ATUNED creative system with the visual and narrative direction developed in the current working session.

The Field is alive.

Points are living signals, not decorative dots.

Awareness is drawn toward vibration.

Connections are living sine-wave relationships.

Repeated connections create pathways.

Tension and resistance increase the visual weight of those relationships.

Stories commingle.

Patterns become conditioned.

Conditioned responses can become increasingly automatic.

The visitor does not need to understand the entire model before experiencing it. The funnel demonstrates the model.

The central creative principle remains:

> **Don't tell them what ATUNED does. Let ATUNED do something to them.**

The existing creative TDD defines the website as the first room of the product and the Field as the interface rather than a background. This document carries that principle into the new animation and narrative system. fileciteturn110file3

# 2. THE HUMAN TRUTH

The previous creative language used:

> You know what you want.
> Something gets in the way.

That is too abstract as the opening of this experience. It assumes a desired outcome that may not be the visitor's immediate concern.

The stronger entry point is:

> **Something happens.**
>
> **You react.**
>
> **Sometimes the reaction happens before you choose it.**

Then:

> **The reaction can repeat.**

Then:

> **What repeats can become automatic.**

Then:

> **What becomes automatic can shape how you live.**

Keep the language grounded in recognizable experiences:

Stress, overwhelm, fear, anger, anxiety, tension, shame, grief, avoidance, people pleasing, compulsion, withdrawal, conflict, self doubt, mental pressure, physical tension, repeated behavior.

The language must point at the actual experience.

Avoid unexplained abstractions.

Avoid unresolved uses of “it.”

Name the thing being discussed.

# 6. POINTS / NODES

Nodes represent points where something is happening.

They must feel alive.

A node begins with:

A faint vibration.
A very small amplitude.
A soft change in luminosity.
A subtle surrounding field.

The movement should be slow enough that the visitor almost discovers it.

The node is a signal, not an alarm.

Preferred sequence:

```text
faint vibration
→ slight amplitude increase
→ soft pulse
→ nearby field responds
```

Avoid flashing, alerts, notification behavior, or aggressive glow.

---

# 7. CONNECTIONS

Connections should not be straight lines by default.

Use a subtle sine-wave form.

```text
NODE ~~~~~ NODE
```

The sine wave represents:

Oscillation.
Polarity.
Duality.
Movement.
Relationship.
Tension.
Change.

A connection begins nearly weightless.

Then:

```text
connection appears
↓
wave begins oscillating
↓
pulse travels through connection
↓
relationship repeats
↓
amplitude / density increases
↓
shadow increases
↓
path becomes more established
```

Complexity is earned by narrative progression.

# 8. TENSION

Tension is a relationship becoming harder to move through.

Visual variables:

Line weight.
Shadow density.
Wave amplitude.
Wave frequency.
Pulse speed.
Local node resistance.
Path persistence.
Field compression.

The animation should communicate:

> **Something is pulling on something else.**

The visitor should understand the relationship without a technical explanation.

---

# 9. CONDITIONING

Repeated reactions can become conditioned within the ATUNED model.

Visual metaphor:

First time:

```text
NODE → weak connection → response
```

Repeatedly:

```text
NODE → established pathway → automatic response
```

The pathway should begin to activate with less prompting.

Copy:

> **The reaction happened again.**

> **And again.**

> **A response repeated often enough can start to feel automatic.**

Then:

> **You don't always choose the reaction. Sometimes the reaction arrives first.**

Do not frame this as a failure of character.

---

# 10. RESISTANCE AND WILL

The deeper concept is that an established response can feel increasingly difficult to interrupt.

Public language should avoid unsupported physiological claims.

Preferred:

> **The more established the response becomes, the harder it can feel to interrupt.**

> **When a reaction has become automatic, choosing differently can take more effort.**

Visual:

A new path appears.

The old path pulls strongly.

The visitor's visual field shows the effort required to move toward the new path.

The point is not “you are weak.”

The point is:

> **There is something established here.**

# 15. FAQ / EXPLANATION LAYER

FAQ should be available when trust questions arise rather than forcing explanation onto every visitor.

Primary questions:

### What is ATUNED actually doing?

ATUNED listens to how you describe your experience, looks for patterns, shows you what it noticed, and lets you confirm or correct the interpretation.

### How does ATUNED know where a pattern sits in my body?

ATUNED uses your reported sensation and location as the starting point and organizes that information through its modeled address system.

These addresses are part of the ATUNED model. They are not a medical diagnosis.

### What happens if ATUNED gets me wrong?

You correct it. Your correction becomes part of the evidence.

### How do I know the reading is accurate?

ATUNED does not ask you to accept the first interpretation as truth. It shows you what it noticed. You test it. You confirm, correct, reject, or redirect it.

### What should I expect to feel?

You may feel something. You may feel nothing. You may notice a change in emotion, attention, thought, sensation, or behavior. No sensation is also information.

### Is ATUNED therapy?

ATUNED is an instrument for self-observation and behavior change. It should not be presented as a replacement for clinical care or as a diagnostic system.

# 25. FIELD PERSISTENCE

The Field must remember visual state across transitions.

If a node was established earlier, it should remain when appropriate.

If a relationship was confirmed, it should remain visible as part of the developing structure.

If a hypothesis was rejected, it must not reappear as confirmed.

If a pattern is released, its visual state changes rather than simply disappearing.

The Field becomes a visual memory system.

---

# 26. ACCESSIBILITY / REDUCED MOTION

All essential meaning must survive without animation.

With reduced motion:

Signal, connection, pattern, network, release, reframe, and verification remain visible as state changes.

No critical information may exist only in motion.

---

# 27. PERFORMANCE

The animation layer should:

Avoid unnecessary DOM objects for large networks.

Prefer Canvas or WebGL where appropriate for high node counts.

Keep text in normal DOM for accessibility.

Separate interaction state from render state.

Use deterministic animation states.

Pause nonessential animation when scenes are not visible.

Respect browser visibility state.

Avoid excessive blur, glow, and filter effects.

Maintain stable performance on normal desktop hardware.

The Field should feel alive without feeling computationally expensive.

---

# 28. RESPONSIVE DESIGN

Desktop is the primary cinematic experience.

The composition must preserve:

Text narrative.
Field.
Interaction.
Progression.

On smaller screens, the Field becomes the upper visual stage and copy remains below or beside it.

The narrative order does not change.

The visual state does not become a static illustration simply because the viewport is smaller.
