# Emmy's library · index

Built 2026-10-15 and 16 from web research and Lance's own sources. About 120,000 words. Open only
the file a task needs; every file is long.

## How to use it

1. **Lenses are angles, not authorities.** Write "Through Rams's lens, this screen has two things
   competing for the eye." Never "Rams would say" and never speak for a living person.
2. **Trust markers.** [V] means checked against a source. [R], [K], [bg], UNVERIFIED and
   [unverified] mean from memory or not confirmed. Treat those as leads: confirm before using
   them as fact, never put them in anything shown to a person, and never quote words marked
   unverified. During the research, web pages could not be opened from this environment, so
   most facts were checked against search results only.
3. **Traditions are a reference, not a doctrine.** The Mechanics of Being governs. A CANON
   correspondence cites the book by line number. A CANDIDATE correspondence is inference until
   Lance rules. Never merge systems, rename MOB terms, or resolve a contradiction yourself: flag it.
4. **Evidence and the real-numbers rule.** Frequency, crystal and energy claims are tradition
   unless the file shows a measurement. Say which is which.
5. **Persuasion serves truth.** Every attention and marketing lens carries the line where its
   method turns into manipulation. Hold Truth, Transparency and Non-Harm.
6. **Better candidates** at the end of each file are proposals. They are not lenses until Lance
   adds them.
