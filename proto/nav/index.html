The bar here carries a wordmark, four doors, a picker and three controls; the build's carries an undo pair and a taller wordmark as well, so its chrome is 65 pixels against this 64 at 1600 and 239 against this 154 at 390. The port was measured on source.html itself and the run is in proto/nav/port.log. Read the figures off that run, not off this table.

A choice is an interactive element with a box on screen at the moment the surface is open. Nothing behind a closed row counts, and the row that holds it counts once. The same rule ran against the build to take the before figures, in proto/nav/count.js.

grouping is not folding, and this is what proves it

A fold moved a host inside another host and the parent's renderer deleted it on the way past. Grouping moves nothing. These checks fail if any integer in the table stops resolving to its own entry, if two doors claim one surface, or if a surface in the bar is missing from the table.
